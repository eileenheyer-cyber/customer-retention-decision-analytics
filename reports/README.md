# Reports

**Status: Planned / In Progress.** No reports have been written yet.

## What Belongs Here

- The final written report summarizing findings and business recommendations, once the analysis is complete.
- Intermediate written summaries for individual project phases (e.g., an experiment analysis write-up, an uplift modeling findings summary), if produced separately from the final report.
- Exported figures or tables referenced by these reports.

## What Should Not Be Stored Here

- Raw analysis code — reports should reference or summarize results produced in `notebooks/`, not contain analysis logic themselves.
- Large raw data exports — include only the summarized figures/tables needed to support the report's narrative.
- Draft or working files that are not intended to be part of the final deliverable set; keep drafts local until finalized.

## Naming Conventions

- Use descriptive, lowercase, underscore-separated names, e.g., `final_report.md`, `experiment_analysis_summary.md`, `uplift_findings_summary.md`.
- Include a version or date suffix if a report is revised significantly after initial completion.
